# Cirava 1.2.4

## What changed

- The optional 7-Zip setting now follows the normal General settings layout. Its disclosure explains that 7-Zip is independent software, where Cirava keeps it, how installation is verified, and where to find the official download page.
- In the upload planner, compression is available only when 7-Zip is enabled and local files are selected. Choose **Compress this upload** to reveal the levels and exact-size preview.
- The Cobalt 20 GB test file is separate from local-file compression. Its option is available only when **Test data** is enabled in Settings.

## Get the release

Download `Cirava-Setup-1.2.4.exe` or the standalone `Cirava.exe` from the [GitHub release](https://github.com/B1progame/Cirava/releases/tag/v1.2.4). The release also includes `update-manifest.json` for checksum-verified updates.
