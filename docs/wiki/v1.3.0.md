# Cirava 1.3.0

## Highlights

- Added a dedicated Google Photos workspace with a Drive media browser and secure Google Photos Picker selection.
- Added resumable uploads of local photos and videos to Google Photos, with optional new-album creation.
- Added a safe handoff to Google Photos in the default browser for cloud-photo deletion. Unsent local items can be removed from Cirava's selection without deleting the source file.
- Added shared-drive and pasted-link destinations to the upload planner.
- Improved album controls, dropdown dismissal, keyboard handling, and transfer-route animation.
