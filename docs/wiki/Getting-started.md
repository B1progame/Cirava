# Get started

## Install Cirava

Download Cirava from [GitHub Releases](https://github.com/B1progame/Cirava/releases/latest). Choose the setup program if you want Windows to install the app, or choose `Cirava.exe` to run the standalone version. Keep the app in a folder you can find again; do not run it from inside the downloaded archive.

## Connect Google Drive

The first-run screen asks for a Google Desktop OAuth client ID. Cirava does not ask for your Google password. If you have not created a client ID, follow [Google Drive setup](Google-Drive-setup). The account must be allowed by the consent screen configuration. For an app in testing, add that account as a test user.

After entering the client ID, choose the sign-in action. Cirava opens Google's sign-in page in your browser. Review the account and requested access there, then return to Cirava when sign-in finishes.

## Make a first transfer

Open Drive and confirm that your folders load. To upload, choose files or a folder, select a destination, review the plan, then hold **Start upload** until it confirms. To download, choose a Drive item and use its download action. See [Uploading](Uploading) or [Downloading](Downloading) for the full flow.

The transfer panel shows the current state, transferred bytes, total size, queue count, speed, and an estimated time remaining when Cirava has enough speed data. The estimate changes as the connection changes.
