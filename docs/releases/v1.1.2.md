## Cirava 1.1.2

### Highlights

- Added a live time-remaining estimate to the transfer panel, calculated from remaining bytes and aggregate transfer speed.
- Clarified upload startup, connection, retry, and queued states so transfer progress is easier to understand.
- Fixed the empty-folder “Upload files” button so it opens the same upload planner as the main Upload action.
- Automatically dismisses the disabled 20 GB test-upload notice after it has been visible long enough to read.
- Added researched Drive transfer-performance findings and a benchmark plan to the repository documentation.
- Added a task-based wiki guide for setup, transfers, privacy, and troubleshooting.

### Downloads

- `Cirava-Setup-1.1.2.exe` — Windows installer.
- `Cirava.exe` — standalone Windows app.
- `update-manifest.json` — checksummed in-app update metadata for both app and installer.
