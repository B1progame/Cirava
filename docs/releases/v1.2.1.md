## Highlights

- Replaced the browser's native folder-name prompt with an in-app dialog that matches Cirava's theme and supports keyboard dismissal.
- Made download pause and cancel take effect between streamed blocks, instead of waiting for an entire request to finish.
- Validate Drive byte-range responses before using them, and reject mismatched or ignored ranges instead of silently treating them as valid partial data.
- Wait for the Windows notification-area message loop before reporting tray controls as ready, with a retry when startup is delayed.
- Corrected the README logo link and refreshed the release/version guidance.
