# Cirava 1.3.0

This release adds a separate Google Photos workspace and expands destination handling for Drive uploads.

## Highlights

- Browse accessible image and video files across My Drive and shared drives, with search and paginated loading.
- Select Google Photos items through Google's secure Picker instead of silently scanning the entire Photos library.
- Upload local photos and videos to Google Photos with resumable transfers, optionally placing an upload in a newly created album.
- Open a selected cloud photo in Google Photos using the system browser when you want to delete it there; local unsent items can be removed from Cirava's selection without deleting their source files.
- Choose shared-drive upload destinations directly or resolve a shared-drive/folder link in the upload planner.
- Improve the upload planner's album layout and folder-location menu behavior, including keyboard and outside-click dismissal.
- Keep the transfer route animation to three moving file icons while varying icon styles and motion.

## Downloads

- `Cirava-Setup-1.3.0.exe` — Windows installer.
- `Cirava.exe` — standalone Windows app.
- `update-manifest.json` — checksum-verified in-app update metadata for both app and installer.

Google Photos library access is limited to items the user selects in the Picker. Deletion is completed by the user in Google Photos; Cirava does not delete Photos library content through its API integration.
