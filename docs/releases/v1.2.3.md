## Highlights

- Fixed the in-app update handoff. Cirava now waits for the updated app to confirm startup and restores the previous app if the new version fails to launch.
- Kept Google account data in the Windows user profile during in-app updates.
- Reworked the upload planner's 7-Zip compression-level picker into clear, accessible level buttons.
- Added regression coverage for the compression picker and updater startup/rollback behavior.
