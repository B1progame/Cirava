## Highlights

- Improved large Drive downloads with streamed byte ranges, persistent HTTP connections, and throughput-aware parallelism. Completed ranges remain reusable after interruption.
- Small uploads now use a single multipart request; larger files continue to use resumable uploads.
- Added optional 7-Zip compression with a measured size-and-savings preview before an archive is queued. Cirava-created archives can be verified and extracted automatically when the feature is enabled.
- Added hold-to-confirm for downloads, including Drive row actions and context-menu file and folder downloads.
- Improved transfer feedback with clearer queue notifications, elapsed time, remaining-time estimates, and progress animation.
- Kept transfer controls accessible from the system tray, including page navigation and pause, resume, and stop actions.

## Downloads

- `Cirava-Setup-1.2.0.exe` — Windows installer.
